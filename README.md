# Enterprise AI Platform - Core Infrastructure

Plataforma empresarial impulsada por IA


## 🛠 Tecnologías Utilizadas
* **Infraestructura:** Docker, MySQL 8.0
* **Data Engineering & Generación:** Python 3.13, SQLAlchemy, Faker, FPDF2
* **Entorno:** Entorno virtual nativo (`venv`), gestión de secretos (`dotenv`)

## 🚀 Guía de Instalación y Uso

### 1. Requisitos Previos
* Docker (o OrbStack) instalado y ejecutándose.
* Python 3.13 o superior.

### 2. Configuración del Entorno
